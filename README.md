## 写真について
料理写真は、商用利用条件を確認しやすい Wikimedia Commons のライセンス付き画像を「仮写真」として使用しています。
2Q PHỞの実際の商品写真ではありません。公開前に、できれば実際のお店・料理の写真へ差し替えることをおすすめします。

## 後で変更する場所
### ロゴ
index.html の「2Q PHỞ」部分を logo.png に変更できます。

### Instagram
index.html のSNS欄にInstagram URLを追加できます。

### Google Maps
Google Mapsの「共有 → 地図を埋め込む」で取得したiframeを、index.htmlのmap部分に入れられます。

本物の料理写真を送っていただければ、料理ごとに写真を割り当て直せます。
