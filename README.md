# 2Q PHỞ Website

## 使い方
1. `images` フォルダに写真を入れます。
2. ロゴを `images/logo.png` にして、`index.html` のコメント部分を変更します。
3. SNSのURLを `index.html` の `href="#"` に入れます。
4. 店舗住所・営業時間・電話番号・Google Mapsを変更します。
5. GitHubへアップロードして GitHub Pages をONにします。

## 写真ファイル名
メニュー写真は `script.js` の `img` に書いてあるファイル名と同じ名前にしてください。

例：
- images/pho-bo.jpg
- images/bun-bo-hue.jpg
- images/banh-mi.jpg
- images/nem-ran.jpg
- images/goi-cuon.jpg

写真がまだない場合でもサイトは表示できます。後から写真を入れれば自動的に表示されます。
